# PXL visual gallery assets

Original PXL-generated visual examples for the PXL skill report.

- `characters/`: native pixel canvas sprites at 32, 48, and 64 px height.
- `rig/`: separate transparent head/torso/limb PNGs, parts map and bone/pivot debug visualization. The rig is custom code in PXL; PXL itself does not provide a skeletal runtime rig.
- `animation/`: animated GIF previews plus PXL frame-strip PNGs. Timing/source frame metadata is included as JSON where PXL emits it.
- `props/`: transparent props and a staged scale comparison.
- `source/pxl_visual_examples_v2.px.js`: editable PXL source for the examples.

The 32→64 sprite detail gate passed: size ×1.93, drawn regions ×2.61, shading tones ×1.71, pixel echo 28%. This is a technical detail-gain check, not an art-quality rating.
